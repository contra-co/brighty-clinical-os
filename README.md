# Brighty Clinical OS AI — Next.js Prototype

Interactive local prototype based on the Brighty Clinical OS AI blueprint and the approved black/gold Brighty visual direction.

## Run on your computer

1. Install **Node.js 20+** from nodejs.org.
2. Open Terminal / PowerShell inside this folder.
3. Run:

```bash
npm install
npm run dev
```

4. Open:

```text
http://localhost:3000
```

## What is included

- Staff / Management mobile workflows
- Patient Case, Smile Design, Treatment Plan, Gates, Clinical Execution
- Lab Sheet + Lab Tracking
- AI Case Assistant + Voice Update
- Follow-up, Patient Concerns, Notifications
- Medical Director and CEO decision views
- Audit Trail, Users, Roles and Permissions
- Patient App: Home, Journey, Media, Smile Design, Progress, Appointments, Aftercare, Dr. Abdallah AI Companion, Concern Escalation, Before/After, Consent
- Desktop prototype navigator so every screen can be reviewed from a computer
- Responsive mode: on a narrow/mobile browser the phone frame disappears and the app fills the screen

## Notes

This is a front-end clickable prototype. It does **not** yet include a real database, authentication backend, AI provider, file upload storage, or live clinical integrations.
